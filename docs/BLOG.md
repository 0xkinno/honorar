# A citation is a claim. A payment should be proof.

Draft companion article.

Assistants read writers all day. When a source is cited, we assume it was used, and when a payment is shown, we assume it settled. Both assumptions are wrong more often than they should be. Models cite sources they never used, and nanopayments that make sub-cent pricing possible never appear on chain one by one.

Honorar treats the model as a proposer and code as the decider. A quote is paid only if it is in the source and in the answer. Each verified quote becomes a leaf in a Merkle tree whose root is committed in the same transaction that pays the writer. Reading fees travel through Gateway, and a reconciler tracks each one from authorization to the batch that settled it.

Numbers for the post will come from `evidence/` once the mainnet runs and the benchmark complete.
